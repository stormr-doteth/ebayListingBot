Set up eBay (one time)
  1. Open developer.ebay.com → Application Keys. In the {{ 'Sandbox' if sandbox else 'Production' }} box, copy the App ID (Client ID) and Cert ID (Client Secret).
  2. On that page click User Tokens next to the keyset → Get a Token from eBay via Your Application. Copy the RuName (looks like Name-Name-App-abcdef). Add one if there's none.
  3. On that RuName, set Your auth accepted URL to https://example.com and save.
  4. Paste the three values below, then tap Save. They're stored on this Mac only.
